## Phase 2 · Veeva integration

- [ ] **Подключить реальный Veeva API** — `shared/tracking/veeva-clm.js` уже структурирован под это. Заменить заглушки на реальные вызовы `com.veeva.clm.createRecord`.
- [ ] **Связывание со sluggable Veeva slide IDs** — при компиляции под Veeva каждый слайд получает свой `keyMessageId`. Прописать соответствие в `manifest.json`.
- [ ] **Offline mode** — Veeva работает офлайн. Все шрифты, скрипты должны быть локально, без CDN.
  - Скачать Vue 3 prod build → `assets/vendor/vue.global.prod.js`
  - Скачать Fraunces + JetBrains Mono → `assets/fonts/`
  - Заменить CDN-ссылки на локальные

## Phase 3 · Build system

- [ ] **Vite setup** — для нормальной сборки модульной версии:
  ```bash
  npm create vite@latest . -- --template vue
  npm install
  npm run build
  ```
  Особенности под Veeva:
  - `base: './'` (relative paths — Veeva не любит абсолютные)
  - `build.assetsInlineLimit: 0` (не инлайнить ассеты в base64, Veeva сам кеширует)
  - Outdir = `dist/`, потом упаковать в zip по структуре Veeva.

- [ ] **Pack script** — bash или node-скрипт, который собирает финальный zip для загрузки в Veeva Vault.
